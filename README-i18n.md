# Site interface localization (2026-10-24)

- Language choices: Japanese (default), English and Turkish; links carry \`?lang=ja|en|tr\`, choice is stored locally when storage is allowed.
- Scope: shared UI, warnings, navigation, labels, and **96 curated Offering descriptions**. Proper names, unknown source claims and unverified descriptions are not automatically translated.
- No machine translation on user-entered text or scraped claims.
- Original Japanese HTML is the source, remains visible without JavaScript. English/Turkish are enhancements; untranslated items are explicitly labeled as remaining in Japanese.
- The localization script is loaded by home, listings, events, the two previous detail pages and all 92 static \`places/\` pages. Generated profile pages use the same linked script.
- All links preserve language, current search parameters and hashes. Locale can be set explicitly in a share URL.
- For a full content translation release, review location/organization titles and evidence-backed claims with bilingual editorial QA before representing translations as official.
