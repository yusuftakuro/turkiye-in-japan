# Türkiye in Japan — v1.1 proposed public-safe export

This is a **data-only candidate projection**, not the live website database or a guarantee that any venue is operating. Existing v1.0 records: 41 Entity; proposed additions: 26 provisional Entity with status `unknown`; 28 additional researched identities remain for review.

The authoritative **full** v1.1 candidate dataset is separately retained in the user’s private ChatGPT Library as a ZIP with full provenance, location visibility, 222 legacy Evidence mappings, and scripts. This public repository deliberately omits all non-public and office-only Location addresses and corresponding Claims. Never try to reconstruct a public office/shop from a non-public address.

`new_claim_evidence.csv` stores the new Entity, Offering and Channel statements and supporting URLs. The full 271-Claim fixture lives in the private archive.

Before implementing the site, filter results by user-relevant actual offerings and do not advertise `unknown` as open, available, or bookable.

Execute the bundled private build_v11.py and export_public.py against the accepted SSOT v1.0 ZIP + researched Wave001–003 ZIP, then run `python3 scripts/check_canonical_public.py` in this GitHub repository.
